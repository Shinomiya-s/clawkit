# Essential Skills Pack

Core skills that most OpenClaw users will want.

## Included

| Skill | Purpose |
|-------|---------|
| skill-vetter | Check skills for security issues before installing |
| self-improving-agent | Remember your corrections and preferences |
| mcp-duckgo | Search the web and fetch content |
| desktop-control | Control mouse, keyboard, take screenshots |

## Why these?

- **Security first** - vet skills before trusting them
- **Learn from mistakes** - the AI actually remembers what you tell it
- **Web access** - search and scrape without opening a browser
- **Desktop control** - automate repetitive GUI tasks

Install with: `clawkit install essential`
